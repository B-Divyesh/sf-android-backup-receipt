    How it works

    How the folder check works

    1. 01

      Choose folder pairs

      The Android app uses Android’s file picker. This website uses your browser’s folder picker. Add every folder pair you want to check.

    2. 02

      Create file fingerprints

      Files through 32 MiB use a complete fingerprint (SHA-256). Larger files use a clearly marked sampled fingerprint.

    3. 03

      Keep the receipt

      Download a detailed receipt (JSON) or a spreadsheet-ready issue list (CSV).

    ↗
    Check a WebDAV or S3 backup

    Android: Install a WebDAV or S3 document provider, then select its backup folder. This app reads only that selected folder.

    Website: Open the mounted remote folder on another computer. Download its backup folder record. Move that JSON file here, then use Import backup record.

    Limits

    This does not back up your phone.

    It checks selected photos, downloads, documents, and app-export folders. It cannot see protected app data, messages, system settings, or unselected folders.

    Matching file names and fingerprints show that copies agree now. They cannot promise that a storage provider will keep them. Keep two copies.

    Android app

    Choose folders with Android’s file picker.

    The Android app asks you to select each phone or backup folder. It keeps read access only for folders you select.

    It cannot scan your full device or protected app data.

    1. Download the Android app package (APK). Advanced users can download APK checksums.
    2. Open it on Android and allow installation from your browser or file manager if Android asks.
    3. Choose each phone folder and backup folder in Android’s file picker. Then issue one combined receipt.
