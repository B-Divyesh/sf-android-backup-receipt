Policy / Privacy

Your files stay yours.

Effective 28 August 2026.

What the app reads

Android Backup Receipt reads only folders and manifest files you explicitly select. In the Android app, the system Storage Access Framework grants access to the selected tree only; in the web app, the browser file picker does the same. The app processes relative paths, file sizes, modification dates, and SHA-256 fingerprints on your device. It does not upload file contents or inventory data to Sociobot.

What is stored

The latest source and destination inventories are stored in IndexedDB on this device so an interrupted check can resume; “Start another check” clears them. Exported receipts go wherever you choose. If Migration Kit is active, up to 20 receipt summaries are also stored in IndexedDB. License tokens and a daily verification result are stored in localStorage. You can clear the archive in the app and clear all data through browser settings. The Android package excludes this private app state from cloud backup and device transfer.

Network access

The app contacts the Sociobot billing API only when you buy or verify a license. That request includes the license token and normal connection metadata such as IP address. We do not add analytics, advertising pixels, or third-party scripts.

Media metadata

The app does not parse EXIF, location, thumbnail, or media-library metadata. Names and timestamps may still reveal personal information inside an exported receipt, so store it carefully.

Contact

Questions can be sent to privacy@sociobot.in.
