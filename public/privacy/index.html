Policy / Privacy

How Android Backup Receipt handles your files

Effective 28 August 2026.

What the app reads

Android Backup Receipt reads only folders and saved folder records you select. Android’s file picker grants read access to each selected folder. The browser version uses its file picker. The app compares names, sizes, dates, and file fingerprints on your device. It does not upload file contents or folder records to Sociobot.

What is stored

The latest phone and backup folder records use this browser’s local database. This lets an interrupted check resume. “Start another check” clears them. Downloaded receipts go where you choose. Migration Kit can store up to 20 receipt summaries in the same database. Your browser stores the license and its daily check separately. You can clear the archive in the app. Browser settings can clear all stored data. The Android app excludes this private state from cloud backup and device transfer.

Network access

The app contacts the Sociobot billing API only when you buy or verify a license. That request includes the license token and normal connection metadata such as IP address. We do not add analytics, advertising pixels, or third-party scripts.

Media metadata

Saved folder records do not include photo location, thumbnails, or hidden camera details. Names and dates may reveal personal information in a downloaded receipt. Store it carefully.

Contact

Questions can be sent to privacy@sociobot.in.
