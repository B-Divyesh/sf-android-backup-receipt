Scope / 03

This does not back up your phone.

It verifies user-selected photos, downloads, documents, and app-export folders. It cannot see protected app data, messages inside apps, system settings, or anything you do not select.

Matching filenames and bytes are strong evidence, not a guarantee that a remote provider will retain them forever. Keep two copies of irreplaceable files.

Android app / SAF

Inspect folders with Android’s own picker.

The Android app asks you to select each source or destination tree. It keeps only that selected-tree permission, so it cannot scan your full device or protected app data.

  1. Download the APK and confirm the published SHA-256 checksum.
  2. Open it on Android and allow installation from your browser or file manager if Android asks.
  3. Choose the phone folder and its copied destination in the Android file picker, then issue the receipt.
